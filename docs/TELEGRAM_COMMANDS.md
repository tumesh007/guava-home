# Telegram Commands

Control your Guava Home smart home controller via Telegram bot.

## Available Commands

### Device Control
- `/status` - Get current device status
- `/lights` - Control lighting
- `/relay` - Control relay outputs
- `/temp` - Get temperature readings
- `/humidity` - Get humidity readings

### Configuration
- `/config` - View current configuration
- `/setname <name>` - Set device name
- `/restart` - Restart the device

### Notifications
- `/alerts on|off` - Enable/disable alerts
- `/report` - Get comprehensive status report

For more details, see the main README.md
