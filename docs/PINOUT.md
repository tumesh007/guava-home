# ESP32 DevKit V1 Pinout Reference

## Pin Assignments

### GPIO Pins
- GPIO 0: Button/Reset
- GPIO 2: LED (onboard)
- GPIO 4: Relay 1
- GPIO 5: Relay 2
- GPIO 12: Relay 3
- GPIO 13: Relay 4
- GPIO 14: Status LED
- GPIO 15: RFID Reader (RX)
- GPIO 16: RFID Reader (TX)

### Communication
- GPIO 1: UART0 TX
- GPIO 3: UART0 RX
- GPIO 17: I2C SDA
- GPIO 18: I2C SCL
- GPIO 19: SPI MISO
- GPIO 23: SPI MOSI
- GPIO 25: SPI CLK

### Power
- 3.3V: Logic power
- GND: Ground reference
- 5V: USB/External power
